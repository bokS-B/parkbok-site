줄바꿈 제거

한글·PDF에서 복사할 때 생기는 불필요한 줄바꿈과 공백을 한 번에 정리. 문단은 유지하는 스마트 모드.

글자수 세기

공백 포함·제외, 바이트, 단어·줄·문단 수. 자소서 글자수 제한 확인.

목록 → SQL IN절

한 줄씩 적힌 값을 ('A', 'B', 'C') 형태로. 따옴표·중복 제거·숫자 자동 감지.

중복 줄 제거 · 정렬

같은 줄 지우기, 빈 줄 제거, 가나다·숫자·길이 순 정렬.

목록 ↔ 한 줄

세로 목록을 쉼표로 이은 한 줄로, 또는 그 반대로.

이 도구들은 이렇게 쓰입니다

  • 자소서·논문: 한글(HWP)이나 PDF에서 복사한 글을 웹 입력 칸에 붙일 때 줄마다 끊긴 줄바꿈을 지우고, 글자수 제한에 맞는지 확인합니다.
  • 행정·사무: 엑셀 한 열을 복사해 쉼표로 이은 목록을 만들거나, 명단에서 중복을 지우고 가나다순으로 정리합니다.
  • 데이터·개발: ID 목록을 SQL WHERE id IN (...) 조건으로 바로 바꿉니다.

HWP 파일 자체를 열어야 하면 HWP 뷰어에서 본문을 복사한 뒤 여기로 가져오세요.
