목록 → SQL IN절 변환

엑셀 한 열이나 한 줄씩 적힌 값을 붙여 넣으면 ('A', 'B', 'C') 형태로 바꿔 줍니다. 따옴표 안의 작은따옴표는 자동으로 ''로 바꿉니다.

값을 붙여 넣으면 바로 변환됩니다. 입력한 내용은 어디에도 전송되지 않습니다.

사용 예

엑셀에서 주문번호 열을 복사해 붙여 넣고 열 이름에 order_no를 적으면 아래처럼 나옵니다.

order_no IN ('20240101-001', '20240101-002', '20240102-003')

숫자만 있으면 "자동" 설정에서 따옴표를 붙이지 않습니다: id IN (1001, 1002, 1003)

주의할 점

  • Oracle은 IN절에 1,000개까지만 넣을 수 있습니다. 넘으면 이 도구가 경고를 띄우며, 그때는 임시 테이블이나 여러 조건으로 나누세요.
  • 값 안의 작은따옴표(O'Brien)는 'O''Brien'으로 자동 처리합니다. 큰따옴표 모드에서는 큰따옴표를 두 번 씁니다.
  • 앞에 0이 붙는 번호(0012)는 "자동"에서 숫자로 보고 따옴표를 뺍니다. 문자열 열이면 "작은따옴표"를 직접 고르세요.
  • 앞뒤 공백은 지웁니다. 빈 줄은 무시합니다.

자주 묻는 질문

반대로 IN절을 세로 목록으로 풀 수 있나요?
목록 ↔ 한 줄에서 "한 줄 → 목록"을 고르고 붙여 넣으면 쉼표 기준으로 나뉩니다. 따옴표는 찾아 바꾸기로 지우세요.
Excel 수식이나 Python 리스트 형태도 되나요?
따옴표를 "큰따옴표"로, 열 이름을 비우면 ("A", "B")가 되어 Python·JSON 배열에 거의 그대로 쓸 수 있습니다. 괄호만 대괄호로 바꾸세요.
