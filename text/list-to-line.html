목록 ↔ 한 줄 변환

세로 목록을 쉼표로 이은 한 줄로, 또는 쉼표·공백으로 나열된 한 줄을 세로 목록으로 바꿉니다.

목록을 붙여 넣으면 바로 변환됩니다. 입력한 내용은 어디에도 전송되지 않습니다.

이럴 때 씁니다

  • 엑셀 한 열에 있는 이메일 주소를 복사해 메일 받는 사람 칸에 넣을 a@x.com, b@x.com 형태로 만들기 (구분자 쉼표 또는 세미콜론)
  • 쉼표로 나열된 해시태그·키워드를 한 줄에 하나씩 풀어 엑셀에 붙이기
  • 세로 목록을 검색창·필터에 넣을 공백 구분 한 줄로 만들기

자주 묻는 질문

"한 줄 → 목록"에서 구분자는 어떻게 정하나요?
고른 구분자로 자릅니다. 쉼표·세미콜론·탭·세로줄이 섞여 있으면 "쉼표"를 고르세요 — 이때는 쉼표·세미콜론·탭·세로줄·줄바꿈을 모두 구분자로 봅니다.
SQL IN절처럼 따옴표도 붙이고 싶어요.
목록 → SQL IN절을 쓰세요. 따옴표·괄호·열 이름까지 한 번에 붙습니다.
결과를 다시 다른 설정으로 바꾸고 싶어요.
"결과를 원본으로" 버튼을 누르면 결과가 원본 칸으로 옮겨져 이어서 처리할 수 있습니다.
