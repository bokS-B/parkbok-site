Générateur de dégradé

Choisissez couleurs et angle, copiez le CSS ou enregistrez un PNG 1920×1080

Générateur de palettesPipette couleur d'imageVérificateur de contrasteConvertisseur de couleurs
Comment ça marche

Tout est calculé dans votre navigateur. Rien n'est envoyé à un serveur.

Comment utiliser le CSS ?
Copiez la ligne et collez-la dans n'importe quelle règle CSS, par exemple sur body ou un élément .hero. Seuls linear-gradient et radial-gradient standard sont utilisés : tous les navigateurs actuels les prennent en charge.
Quelle est la taille du PNG ?
1920×1080 pixels, dessiné dans votre navigateur avec les mêmes couleurs et le même angle que l'aperçu. Rien n'est envoyé.
