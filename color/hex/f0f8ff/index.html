About Alice Blue

Named after Alice Roosevelt Longworth, daughter of Theodore Roosevelt, whose pale blue-grey gowns set a fashion in the early 1900s. It reached CSS through the X11 color list.

  • Palette: pair it with Seashell as a contrasting accent, or with Azure and White Smoke for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (19.58:1, AAA). Write it in CSS as aliceblue or #f0f8ff.
  • Print: about cmyk(6%, 3%, 0%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
