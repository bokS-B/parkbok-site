About Green

CSS 'green' is only half intensity (#008000). The full-brightness #00FF00 is called 'lime', a legacy of the original 16 HTML color names.

  • Palette: pair it with Purple as a contrasting accent, or with Forest Green and Starbucks Green for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: white text reads best on it (5.14:1, AA). Write it in CSS as green or #008000.
  • Print: about cmyk(100%, 0%, 100%, 50%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
