About Deep Pink

A loud, saturated pink with full red and strong blue; one of the most vivid pinks in the CSS list.

  • Palette: pair it with Spring Green as a contrasting accent, or with Fuchsia / Magenta and Netflix Red for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (5.77:1, AA). Write it in CSS as deeppink or #ff1493.
  • Print: about cmyk(0%, 92%, 42%, 0%); a screen color this saturated sits outside the standard CMYK gamut and will print duller, so check a proof or choose a Pantone match.
