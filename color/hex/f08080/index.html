About Light Coral

A soft pinkish red, lighter and pinker than CSS 'coral'.

  • Palette: pair it with Aquamarine as a contrasting accent, or with Hot Pink and Burlywood for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (8.10:1, AAA). Write it in CSS as lightcoral or #f08080.
  • Print: about cmyk(0%, 47%, 47%, 6%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
