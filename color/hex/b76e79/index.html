About Rose Gold

A pinkish metallic tone from gold–copper alloys; on screen it is shown as this flat dusty rose.

  • Palette: pair it with Medium Aquamarine as a contrasting accent, or with Pale Violet Red and Rosy Brown for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (5.52:1, AA). Write it in CSS as #b76e79.
  • Print: about cmyk(0%, 40%, 34%, 28%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
