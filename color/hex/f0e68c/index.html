About Khaki

From the Hindi-Urdu word for 'dust-colored'. Note that CSS 'khaki' is a pale yellow, lighter than the khaki of most uniforms.

  • Palette: pair it with Cornflower Blue as a contrasting accent, or with Burlywood and Pale Goldenrod for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (16.40:1, AAA). Write it in CSS as khaki or #f0e68c.
  • Print: about cmyk(0%, 4%, 42%, 6%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
