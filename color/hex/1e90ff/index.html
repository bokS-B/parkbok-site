About Dodger Blue

A bright azure commonly linked to the blue of the Los Angeles Dodgers baseball team; it reached CSS through the X11 list.

  • Palette: pair it with Dark Orange as a contrasting accent, or with Aqua / Cyan and Blue for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (6.49:1, AA). Write it in CSS as dodgerblue or #1e90ff.
  • Print: about cmyk(88%, 44%, 0%, 0%); a screen color this saturated sits outside the standard CMYK gamut and will print duller, so check a proof or choose a Pantone match.
