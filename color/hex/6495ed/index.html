About Cornflower Blue

Named after the cornflower (Centaurea cyanus). Game developers know it as the default clear color in Microsoft XNA project templates.

  • Palette: pair it with Sandy Brown as a contrasting accent, or with Sky Blue and Medium Slate Blue for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (7.06:1, AAA). Write it in CSS as cornflowerblue or #6495ed.
  • Print: about cmyk(58%, 37%, 0%, 7%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
