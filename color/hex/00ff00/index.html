About Lime

The full green channel of sRGB. HTML named it 'lime' because the keyword 'green' was already used for the darker #008000.

  • Palette: pair it with Fuchsia / Magenta as a contrasting accent, or with Chartreuse and Spring Green for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (15.30:1, AAA). Write it in CSS as lime or #00ff00.
  • Print: about cmyk(100%, 0%, 100%, 0%); a screen color this saturated sits outside the standard CMYK gamut and will print duller, so check a proof or choose a Pantone match.
