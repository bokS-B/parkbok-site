About Pastel Blue

A muted, greyish light blue that keeps a calm, airy feel in pastel palettes.

  • Palette: pair it with Silver as a contrasting accent, or with Light Steel Blue for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (11.78:1, AAA). Write it in CSS as #aec6cf.
  • Print: about cmyk(16%, 4%, 0%, 19%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
