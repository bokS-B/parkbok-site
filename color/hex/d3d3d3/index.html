About Light Gray

A light neutral grey (211 in each channel), common for borders, dividers and disabled controls.

  • Palette: pair it with Gainsboro as a contrasting accent. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (14.03:1, AAA). Write it in CSS as lightgray or lightgrey or #d3d3d3.
  • Print: about cmyk(0%, 0%, 0%, 17%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
