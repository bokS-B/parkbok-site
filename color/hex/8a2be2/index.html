About Blue Violet

A saturated violet that sits between blue and purple; inherited by CSS from the X11 list.

  • Palette: pair it with Yellow Green as a contrasting accent, or with Medium Blue and Medium Orchid for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: white text reads best on it (5.96:1, AA). Write it in CSS as blueviolet or #8a2be2.
  • Print: about cmyk(39%, 81%, 0%, 11%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
