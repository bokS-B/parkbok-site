About Thistle

A pale greyish purple named after thistle flowers.

  • Palette: pair it with Light Gray as a contrasting accent, or with Silver for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (12.36:1, AAA). Write it in CSS as thistle or #d8bfd8.
  • Print: about cmyk(0%, 12%, 0%, 15%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
