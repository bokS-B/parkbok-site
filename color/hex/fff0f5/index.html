About Lavender Blush

An almost-white with a faint pink-lavender tint, as if lavender were blushing.

  • Palette: pair it with Azure as a contrasting accent, or with Ghost White and Seashell for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (19.03:1, AAA). Write it in CSS as lavenderblush or #fff0f5.
  • Print: about cmyk(0%, 6%, 4%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
