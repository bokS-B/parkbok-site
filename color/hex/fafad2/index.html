About Light Goldenrod Yellow

At 20 letters, 'lightgoldenrodyellow' is the longest CSS color keyword.

  • Palette: pair it with Gainsboro as a contrasting accent, or with Champagne and Beige for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (19.67:1, AAA). Write it in CSS as lightgoldenrodyellow or #fafad2.
  • Print: about cmyk(0%, 0%, 16%, 2%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
