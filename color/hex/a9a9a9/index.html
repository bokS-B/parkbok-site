About Dark Gray

A famous CSS quirk: 'darkgray' is lighter than plain 'gray' (#808080), because the X11 and HTML color lists were merged without reconciling them.

  • Palette: pair it with Pastel Purple as a contrasting accent. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (8.94:1, AAA). Write it in CSS as darkgray or darkgrey or #a9a9a9.
  • Print: about cmyk(0%, 0%, 0%, 34%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
