About Aqua / Cyan

Full green plus full blue light with no red. 'Aqua' is the HTML 4 name and 'cyan' the printing name; both keywords give the same value, and cyan is also one of the four CMYK process inks.

  • Palette: pair it with Red as a contrasting accent, or with Spring Green and Facebook Blue for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (16.75:1, AAA). Write it in CSS as aqua or cyan or #00ffff.
  • Print: about cmyk(100%, 0%, 0%, 0%); a screen color this saturated sits outside the standard CMYK gamut and will print duller, so check a proof or choose a Pantone match.
