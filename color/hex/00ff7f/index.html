About Spring Green

In color theory 'spring green' sits exactly between green and cyan on the color wheel.

  • Palette: pair it with Deep Pink as a contrasting accent, or with Lime and Aqua / Cyan for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (15.61:1, AAA). Write it in CSS as springgreen or #00ff7f.
  • Print: about cmyk(100%, 0%, 50%, 0%); a screen color this saturated sits outside the standard CMYK gamut and will print duller, so check a proof or choose a Pantone match.
