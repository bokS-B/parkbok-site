About Cadet Blue

A muted grey-blue associated with military cadet uniforms; kept in CSS from the X11 list.

  • Palette: pair it with Rose Gold as a contrasting accent, or with Medium Sea Green and Slate Gray for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (6.88:1, AA). Write it in CSS as cadetblue or #5f9ea0.
  • Print: about cmyk(41%, 1%, 0%, 37%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
