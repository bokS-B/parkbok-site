About Light Pink

Another CSS quirk: 'lightpink' is slightly darker and more saturated than plain 'pink' (#FFC0CB).

  • Palette: pair it with Pale Turquoise as a contrasting accent, or with Pink and Peach Puff for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (12.71:1, AAA). Write it in CSS as lightpink or #ffb6c1.
  • Print: about cmyk(0%, 29%, 24%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
