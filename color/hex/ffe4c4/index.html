About Bisque

Named after bisque (biscuit) ware, unglazed pottery fired once, which has this pale peach tone.

  • Palette: pair it with Powder Blue as a contrasting accent, or with Pink and Lemon Chiffon for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (17.15:1, AAA). Write it in CSS as bisque or #ffe4c4.
  • Print: about cmyk(0%, 11%, 23%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
