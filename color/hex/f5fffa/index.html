About Mint Cream

A near-white with a cool mint tint.

  • Palette: pair it with Snow as a contrasting accent, or with Honeydew and Azure for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (20.57:1, AAA). Write it in CSS as mintcream or #f5fffa.
  • Print: about cmyk(4%, 0%, 2%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
