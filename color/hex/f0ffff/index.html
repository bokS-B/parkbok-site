About Azure

From the Persian word for lapis lazuli via Old French azur. In CSS it is an almost-white pale cyan, much lighter than the deep blue 'azure' of heraldry.

  • Palette: pair it with Lavender Blush as a contrasting accent, or with Mint Cream and Alice Blue for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (20.45:1, AAA). Write it in CSS as azure or #f0ffff.
  • Print: about cmyk(6%, 0%, 0%, 0%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
