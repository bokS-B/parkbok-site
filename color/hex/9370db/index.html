About Medium Purple

A soft lavender-purple, lighter and bluer than CSS 'purple'.

  • Palette: pair it with Dark Khaki as a contrasting accent, or with Cornflower Blue and Orchid for a softer, analogous scheme. Lighter and darker steps are in the shade row above.
  • Web: black text reads best on it (5.58:1, AA). Write it in CSS as mediumpurple or #9370db.
  • Print: about cmyk(33%, 49%, 0%, 14%); it falls within the usual CMYK range, but check a printed proof because paper and ink shift the tone.
