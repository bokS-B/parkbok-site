Comment ça marche

Tout est calculé dans votre navigateur. Rien n'est envoyé à un serveur.

Comment fonctionne le verrou ?
Appuyez sur le cadenas d'une couleur : elle reste pendant que la barre d'espace ou le bouton Nouvelles couleurs remplace les autres. Appuyez à nouveau pour la libérer.
Comment partager une palette ?
L'adresse de la page se termine par les cinq couleurs, par exemple #ff5733-33ff57-…. Copiez l'adresse : la même palette s'ouvre chez tout le monde.
