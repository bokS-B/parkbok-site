HWP를 PDF로 바꾸는 방법 (무료, 설치 없음)

HWP를 받는 쪽에 한글이 없을 때 가장 안전한 전달 방법은 PDF입니다. 한글 프로그램이 있으면 "인쇄 → PDF로 저장"이면 끝이지만, 없을 때는 아래 방법을 쓰세요.

브라우저에서 PDF로 저장하기

  1. parkbok.com HWP 뷰어를 엽니다.
  2. HWP 또는 HWPX 파일을 끌어다 놓습니다. 페이지가 화면에 그려집니다.
  3. PDF로 저장 (인쇄) 버튼을 누릅니다. 브라우저 인쇄 창이 열립니다.
  4. 대상(프린터)을 "PDF로 저장"으로 바꿉니다. 맥은 왼쪽 아래 "PDF" 메뉴, 안드로이드는 "PDF로 저장"을 고릅니다.
  5. 여백을 "없음" 또는 "최소"로, 배경 그래픽을 켜면 원본과 더 비슷해집니다.
  6. 저장을 누르면 PDF 파일이 만들어집니다.

주의할 점

  • 페이지 크기가 A4가 아니면(B5, 신문지 등) 인쇄 창에서 용지 크기를 맞춰 주세요.
  • 한글 전용 글꼴(함초롬바탕, HY견고딕 등)은 다른 글꼴로 대체됩니다. 줄 바꿈 위치가 조금 달라질 수 있습니다.
  • 수식, 글맵시, 복잡한 도형은 빠지거나 다르게 보일 수 있습니다. 제출용 최종본은 원본 프로그램에서 확인하세요.
  • 암호가 걸린 문서는 열리지 않습니다. 보낸 사람에게 암호를 푼 파일이나 PDF를 요청하세요.

파일을 올리지 않아도 되는 이유

대부분의 "HWP PDF 변환" 사이트는 파일을 자기 서버로 올려 변환합니다. 이력서, 계약서, 사내 문서를 그렇게 보내는 건 찜찜합니다. 이 사이트는 변환 코드가 브라우저 안에서 돌기 때문에 파일이 PC나 휴대폰을 떠나지 않습니다.
