Photo and signature size for online forms in India

Prepare a photo under 20KB, 50KB or 100KB, or resize a signature. Check your application’s pixel dimensions and file-size range first.

Check four requirements first

There is no single photo or signature size for every Indian application. Read the instructions for your exact form and recruitment year. Write down the file format, width × height in pixels, minimum size and maximum size.

Pixels describe image dimensions. KB describes the encoded file size. A 140 × 60 image can be 3KB or 15KB depending on its content and encoding. Changing a filename from .png to .jpg does not convert the image.

How to compress a photo to 20KB, 50KB or 100KB

  1. Open a size button above and select your photo. If your form needs exact dimensions, use crop and resize first.
  2. Check the maximum KB value. Open the format options and choose JPG if your portal requires it. Select JPEG conversion rather than renaming a PNG.
  3. If fixed pixel dimensions are required, turn off resolution reduction. If dimensions are flexible, leaving it on allows a smaller image when quality adjustment alone is insufficient.
  4. Run compression. Check the actual bytes, pixel dimensions and readability. An oversize warning means the target was not met.
  5. Download and preview the file in the application portal. Check any minimum size too: a file below the maximum can still be too small.

PARKBOK’s photo compressor and signature resizer use 1KB = 1,000 bytes. For example, 19,240 bytes is below a 20KB maximum here. Portals may interpret units differently; their actual upload check is the final test.

How to resize a signature without stretching it

  1. Use a clear scan or photograph of your own signature. Open the signature resizer and crop excess space while keeping every stroke.
  2. Enter the required width and height. The 140 × 60, 300 × 100 and 600 × 200 buttons are editable starting points.
  3. Choose the maximum KB. For a 10–20KB requirement, set 20KB and enter 10KB under “Minimum size (optional)”.
  4. Run the tool and inspect the JPG. The signature stays proportional with white padding; the output pixels stay fixed during size adjustment.

A simple 140 × 60 signature may be well below 10KB. PARKBOK flags that result; it does not add empty bytes to manufacture a minimum. Use a clearer original and the dimensions allowed by your form. If the result still falls outside the range, it is not ready for that application.

Why is the upload still rejected?

  • Wrong format: choose JPG output when required, then upload the downloaded file.
  • Wrong dimensions: check width and height separately. Avoid further automatic resizing after setting exact pixels.
  • Too small or too large: check both ends of the size range, not only the maximum.
  • Unclear image: inspect the face or signature strokes at normal size. Smaller bytes are not useful if details become unreadable.
  • Live capture required: use the application portal’s camera workflow. A compressed photo cannot replace it.

Both tools process your image in your browser without uploading the original to PARKBOK. They prepare files; the application authority decides whether a submission meets its requirements.
