HWP와 HWPX의 차이, 무엇을 써야 할까

한글 문서를 받다 보면 .hwp와 .hwpx 두 가지 확장자를 보게 됩니다. 둘 다 한글과컴퓨터의 문서이지만 안쪽 구조가 완전히 다릅니다.

HWP: 2000년대부터 쓰인 바이너리 형식

HWP 5.0은 한글 2002부터 지금까지 쓰이는 형식입니다. 마이크로소프트의 복합 문서(OLE) 컨테이너 안에 압축된 바이너리 데이터가 들어 있습니다. 한글과컴퓨터가 2010년 명세를 공개해서 외부 프로그램도 읽을 수 있게 됐지만, 구조가 복잡해 완벽하게 구현한 무료 프로그램은 드뭅니다.

HWPX: 2014년 만들어진 XML 표준

HWPX는 국가 표준(KS X 6101)으로 지정된 개방형 문서 형식입니다. 워드의 DOCX처럼 ZIP 압축 파일 안에 XML 텍스트가 들어 있습니다. 확장자를 .zip으로 바꿔 풀면 본문이 글자 그대로 보입니다. 그래서 검색, 자동 처리, 다른 프로그램에서 읽기가 훨씬 쉽습니다.

실제 차이 한눈에

항목HWPHWPX
구조바이너리(OLE)ZIP + XML
표준한컴 공개 명세국가 표준 KS X 6101
구버전 한글에서 열기가능한글 2014 이상 필요
외부 프로그램 지원제한적상대적으로 쉬움
공공기관 제출대부분 가능2020년대 들어 권장 추세
악성 코드 위험OLE 취약점 사례 많음상대적으로 안전

무엇을 써야 할까

  • 받는 사람이 어떤 프로그램을 쓰는지 모르면 HWP가 아직 가장 무난합니다. 오래된 한글에서도 열립니다.
  • 공공기관이나 최신 환경이면 HWPX를 권합니다. 정부는 2020년 이후 개방형 문서 사용을 늘리고 있습니다.
  • 확장자만으로 파일의 안전성을 판단할 수는 없습니다. 어느 형식이든 출처를 확인하고, 알 수 없는 발신자가 보낸 파일은 열지 마세요. 사용 프로그램의 보안 업데이트도 유지하세요.
  • 한글에서 "다른 이름으로 저장"에서 형식을 고르면 두 형식을 서로 바꿀 수 있습니다.

프로그램 없이 두 형식 모두 열기
