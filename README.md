# 박복 · 브라우저에서 HWP·HWPX 열기

받은 한글 파일을 설치나 가입 없이 열고, 이름·날짜처럼 짧은 문구를 바꿔 사본을 저장할 수 있습니다. 파일은 기기에서 처리되며 서버로 전송되지 않습니다.

**[HWP·HWPX 뷰어 바로 열기](https://parkbok.com/hwp/)**

1. **HWP 파일 열기**를 눌러 `.hwp` 또는 `.hwpx` 파일을 선택합니다.
2. **문구 편집**에서 바꿀 위치를 찾아 새 문구를 입력한 뒤 변경을 적용합니다.
3. 사본을 만들어 내려받고, 제출할 파일이라면 다시 열어 내용과 서식을 확인합니다.

편집은 지원되는 10MB 이하 문서에서 가능합니다. 복잡한 표, 글꼴, 줄바꿈은 원본과 다르게 보일 수 있습니다.

[맥 사용 가이드](https://parkbok.com/guide/open-hwp-on-mac.html) · [휴대폰 사용 가이드](https://parkbok.com/guide/open-hwp-on-phone.html)

박복은 한컴 공개 HWP 사양을 참고했으며, HWP 파일 해석에 [hwp.js](https://github.com/hahnlee/hwp.js)를 사용합니다.
